# Карта полигона

`polygon_empty_4x4.yaml` загружает актуальную карту с объектами; прежнее имя
сохранено для совместимости с launch-файлом. Начало поля — левый нижний угол,
X вправо, Y вверх. Поле 4 × 4 м, 5 × 5 ячеек по 0.8 м.
Центр ячейки `(i, j)` в `map`: `(0.4 + 0.8*i, 0.4 + 0.8*j)`.

| Ячейка | Назначение | Представление в карте |
|---|---|---|
| 0:0 | Старт | Свободно |
| 1:1 | Остановка, обломки жёлтого здания, парковка | Пока закрыта целиком из-за обломков |
| 1:2, 1:3 | Жёлтое здание | Занято |
| 3:1 | Синее здание | Занято |
| 3:3 | Река | Занято (запрет проезда) |
| 3:4, 4:3 | Мосты | Свободно |

Размеры объектов внутри ячеек пока неизвестны: здания, обломки и река
консервативно занимают всю ячейку. Остальные ячейки свободны.
Парковка 1:1 при таком приближении недоступна как цель движения;
после измерений нужно выделить свободную площадку и контуры обломков.
Мосты пока представлены свободными ячейками без моделирования ограждений.
Река — запретная область, а не физическая стена для сопоставления сканов AMCL.

PGM: 100 × 100 пикселей, разрешение 0.05 м/пиксель, начало изображения
в `map` — (-0.5, -0.5). Внутреннее свободное поле занимает ровно 80 × 80
пикселей; стена толщиной 0.05 м расположена снаружи его границ.
За стеной — неизвестная область. Значения: 0 — занято, 254 — свободно,
205 — неизвестно. Верхняя строка изображения соответствует большему Y.

Разметка 5 × 5 уже настроена как Grid в `rviz/nav2_view.rviz`.
Линии ячеек не являются препятствиями. Цвета зданий и подписи не кодируются
в occupancy-карте: Nav2 использует только занятость.

Для визуальной схемы с цветами см. `polygon_empty_4x4_layout.svg`: стартовая
ячейка отмечена зелёным, закрытые ячейки чёрным, потенциально свободные белым.
SVG не используется `map_server`; рабочая occupancy-карта остаётся в PGM.

После изменения PGM перезапустите map_server (или загрузите YAML через
его сервис load_map), чтобы обновить /map.
