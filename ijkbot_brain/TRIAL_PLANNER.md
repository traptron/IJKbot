# Планер поверх существующей системы

Сначала отдельно запустите существующую систему с Nav2 и драйвером.
Планер не запускает Nav2, не перенастраивает его топики и не публикует скорости.

```bash
source /opt/ros/jazzy/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=42
ros2 launch ijkbot_nav2 trial.launch.py home_x:=0.4 home_y:=0.4 home_yaw:=0.0
```

Поза возврата задаётся в `map`; укажите её в соответствии со стартом системы.
Вход планера — отдельный `/trial/goal_pose`, чтобы Nav2 не получил ту же цель
дважды. Для LLM используется уже существующий параметр без изменения её кода:

```bash
ros2 run ijkbot_brain llm_client --ros-args -p goal_topic:=/trial/goal_pose
```

Ручная цель и наблюдение:

```bash
ros2 topic pub --once /trial/goal_pose geometry_msgs/msg/PoseStamped \
  '{header: {frame_id: map}, pose: {position: {x: 2.0, y: 0.4}, orientation: {w: 1.0}}}'
ros2 topic echo /trial/state
```

Планер отправляет action `/navigate_to_pose`, ждёт успеха, затем минимум
5 секунд неподвижности по свежей `/odom` и возвращается домой через action.
Он отменяет только собственную action-цель при E-STOP, таймауте или потере
одометрии. Остановку выполняет Nav2; планер не является аппаратным E-STOP
и не блокирует команды teleop либо других источников скорости.

При внешней цели `/goal_pose`, другой активной action-цели или активном
старом автомате `/mission/state` планер уступает управление и отменяет
испытание. Новый запуск при занятом Nav2 отклоняется. Не запускайте
испытание одновременно с миссией GUI или teleop. GUI не изменён и не
отображает `/trial/state`; этот топик наблюдается отдельно.

`trial.launch.py` теперь запускает **только планер**. Старые инструкции
о замене запуска Nav2 этим файлом больше не применяются.

Изменения системы из проверки конфликтов отменены до `aece662`.
В той версии `navigation.launch.py` уже содержит синтаксические дубли
(`description`, `condition`, `parameters`) и остатки двух схем локализации.
Они восстановлены при точном откате и не исправляются планером.
Систему из этого файла нельзя запустить до отдельного исправления;
планер рассчитан на уже работающий Nav2.
