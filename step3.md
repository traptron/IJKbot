## 2. Поддерживаемые ориентиры полигона (7 регламентных классов)

Модель и система строго ограничены ровно 7 ориентирами полигона хакатона:

| ID ориентира (`target_landmark_id`) | Описание по регламенту | Ключевые маркеры и алиасы | Стратегия поиска (`search_strategy`) |
|-------------------------------------|------------------------|---------------------------|---------------------------------------|
| `smoke_tower` | Макет здания «Стакан» (D=660 мм, H=800 мм) с ультразвуковым задымлением и подсветкой огня | стакан, башня, дым, задымление, очаг, пожар, возгорание, пар, круглое здание | `inspect_perimeter` |
| `panel_house` | Макет разрушенного панельного дома (1400х500 мм, 2 ячейки) | панельный дом, панелька, разрушенное здание, обрушившийся дом, плиты, руины многоэтажки | `approach_and_scan_facade` |
| `bridges` | Два мостовых перехода (H=55 мм) с боковыми защитными бортиками | мост, мостовой переход, эстакада, путепровод, пандус, ограждения, под мостом | `cross_and_inspect_underpass` |
| `tanker_truck` | Аварийный бензовоз, опрокинутый на бок | бензовоз, автоцистерна, цистерна с топливом, разлив бензина, горючее, перевернутый грузовик | `approach_cautiously_check_leak` |
| `fallen_tree` | Упавшее дерево (макет искусственной берёзы H=450 мм) | упавшее дерево, поваленная береза, ствол дерева, бревно, ветки дерева на проезде | `inspect_around_branches` |
| `car_jam` | Транспортный затор из легковых автомобилей (1:32) | затор, пробка, скопление автомобилей, скопление машин, брошенные легковушки | `scan_adjacent_cells` |
| `debris_pvc` | Завал из фрагментов поливинилхлорида (ПВХ) | завал из ПВХ, фрагменты поливинилхлорида, обломки пластиковых конструкций, строительный мусор, трубы | `inspect_debris_perimeter` |

## 3. Архитектура и надежность модуля `llm_client.py`

### 3.1. Структура контракта (`CommandInterpretation`)
```python
@dataclass
class CommandInterpretation:
    target_landmark_id: str   # Одно из 7 регламентных значений LandmarkID
    search_strategy: str      # Рекомендуемая тактика поиска (snake_case)
    reasoning: str            # Понятное судьям обоснование на русском языке с цитатами
    confidence: float = 1.0   # Оценка уверенности (0.0 .. 1.0)
    source: str = "llm"       # "llm" или "heuristic_fallback"
    latency_sec: float = 0.0  # Время генерации ответа в секундах
    raw_response: Optional[Dict[str, Any]] = None
```

### 3.2. Structured Outputs (JSON Schema Mode)
Запросы к Ollama отправляются с параметром `format: OLLAMA_JSON_SCHEMA`, где `target_landmark_id` строго ограничен enum-списком допустимых ориентиров. Это гарантирует отсутствие галлюцинаций сторонних названий и возвращение чистого JSON без markdown-оберток.

### 3.3. Двухуровневая отказоустойчивость (Deterministic Fallback)
Если в боевых условиях соревнований Ollama окажется временно недоступна, превысит таймаут или произойдет сбой сокета:
- Активируется встроенный **семантический эвристический парсер** (`fallback_heuristic_parse`).
- Он анализирует текст с помощью весовых коэффициентов и регулярных выражений по расширенному словарю синонимов каждого ориентира.
- Робот **никогда не зависает** и гарантированно получает правильный `target_landmark_id`, сохраняя шансы на получение `+100` баллов.

### 3.4. Оптимизация производительности на RTX 5060:
- Добавлен метод `warmup()`: предзагрузка модели в память GPU с параметром `keep_alive: -1`.
- Модель постоянно находится в VRAM (занимает ~4.6 ГБ из 8 ГБ), исключая задержки на чтение с диска при старте попытки.
- Время инференса при горячем запросе составляет **1.5–2.7 секунды** (при ограничении мощности GPU 24 Вт от батареи).

## 4. Интеграция с ROS 2 Jazzy

Пакет может использоваться тремя способами:
1. **Прямой Python API** (для интеграции в конечный автомат миссии `ijkbot_brain/mission_sm.py`):
   ```python
   from ijkbot_brain.llm_client import LLMClient
   client = LLMClient()
   cmd = client.interpret("Пострадавший лежит около задымленного здания Стакан")
   print(cmd.target_landmark_id)  # "smoke_tower"
   ```
2. **Консольная утилита CLI**:
   ```bash
   ros2 run ijkbot_brain llm_client "Замечен человек у перевернутого бензовоза"
   ```
3. **ROS 2 Нода**:
   ```bash
   ros2 run ijkbot_brain llm_client
   ```
   - Подписывается на: `/mission/judge_task` (`std_msgs/msg/String`)
   - Публикует результат: `/mission/target_command` (`std_msgs/msg/String`, JSON)
   - Логирует хронологию через `node.get_logger().info(...)` для демонстрации судьям.
