## Проверка BCF без оборудования

С официального сервера Heltec скачан для анализа файл:

<https://resource.heltec.cn/download/HT-HC01P/BCF/driver_1_15_3/bcf_HC0P.bin>

- Размер: 1150 байт.
- SHA-256: `57c50cb2c1d51187667677b392684285c616ddbf3fe262c3aeece342f446773e`.
- Формат: ELF32 little-endian, RISC-V.
- `.board_config`: 112 байт.
- `.board_desc`: `mf08551`; `.chips`: `mm610x`;
  `.build_ver`: `a49f6ff 17ee8d5`. Таким образом, внутреннее описание
  скачанного `bcf_HC0P.bin` совпадает с обозначением mf08551,
  рекомендованным Heltec. Побайтовое тождество с отдельным файлом
  `bcf_mf08551.bin` не проверялось.
- Региональные секции: AU, CA, EU, IN, JP, KR, NZ, SG, US;
  каждая по 12 байт. **Секции RU нет.**
- Рабочая копия: `/tmp/ijk-halow-inspect/bcf_HC0P.bin` (временное хранилище).

Проверен `firmware.c` драйвера в commit
`b566725bd000aa1854ab406bae786d36014839c2`:

<https://github.com/MorseMicro/morse_driver/blob/b566725bd000aa1854ab406bae786d36014839c2/firmware.c>

1. `morse_bcf_load()` выбирает `.board_config` и секцию `.regdom_XX`
   по фактическому `mors->country`. В таблице fallback нет RU.
   При фактическом регионе RU этот BCF приведёт к сообщению
   `Country code RU not found in BCF`. Это вывод из исходников,
   а не результат нового аппаратного запуска.
2. Ошибка загрузки BCF допускает запуск firmware в failsafe mode.
   Появление сообщения об инициализации firmware само по себе не означает
   успешной настройки радио.
3. При `CONFIG_ANDROID` драйвер отбрасывает каталог и запрашивает только
   имя firmware/BCF. Для сборки из HANDOFF важно учитывать поиск
   `/lib/firmware/mm6108.bin` и `/lib/firmware/bcf_HC0P.bin`, а не полагаться
   только на стандартную установку файлов в `/lib/firmware/morse/`.
4. Формат секций соответствует тому, что читает загрузчик, но это не
   подтверждает совместимость содержимого BCF с firmware 2.2.2:
   firmware отдельно проверяет версию, длину и CRC.

Heltec по-прежнему указывает на странице исходного HT-HC01P диапазон
902–928 МГц и рекомендует `bcf_mf08551.bin`:
<https://heltec.org/project/ht-hc01p/>.
Наличие секции EU в скачанном BCF не доказывает работу конкретного
радиотракта на 868 МГц или соответствие условиям эксплуатации в РФ.
