# Профиль запуска «Город»

Регламент: [Hakaton_Gorod_V2025_1.pdf](https://cup.rtc.ru/cup_rtc/lp/doc/vl/Hakaton_Gorod_V2025_1.pdf).
По нему робот стартует из назначенной организаторами угловой ячейки, следует
знакам движения и запрета поворотов, задерживается на 2 секунды у каждой
«Остановки» и заканчивает маршрут перед «Парковкой». Полигон 5×5, ячейка 0,8 м.

Соберите изменённые пакеты на ноутбуке с распознаванием:

```bash
colcon build --symlink-install --packages-select vision vision_cpp bringup
```

На ноутбуке 2 запустите Pi, Nav2 и камеру:

```bash
./scripts/start_gorod.sh --role operator --pi-host 192.168.1.10
```

Без `--map` запускается SLAM: карты города в репозитории пока нет. Для уже
снятой карты используйте `--map /путь/к/карте.yaml`; тогда включается AMCL.
Стартовую позицию и направление задайте средствами Nav2 после установки робота
на назначенную судьями ячейку. `--mock` оставляет привод в режиме симуляции.
Если камера запущена другим процессом, используйте `--no-camera`.

На ноутбуке 1 запустите распознавание знаков:

```bash
./scripts/start_gorod.sh --role vision --pi-host 192.168.1.10
```

В графической сессии появится окно с рамками знаков. Для другой камеры задайте
`--image-topic /имя/сжатого/топика`; передавать несжатый видеопоток по Wi-Fi
нельзя. В безголовой сессии окно не открывается; `--no-video` отключает его
явно. Логи распознавания выводятся в терминал.

Публикуемые топики:

| Топик | Содержимое |
| --- | --- |
| `/vision/traffic_sign/detections` | JSON-массив кандидатов в текущем кадре |
| `/vision/traffic_sign/confirmed` | JSON подтверждённого знака или `name: null` при потере |
| `/vision/traffic_sign/image/compressed` | JPEG 640×480 или меньше с рамками |

Классы: `straight`, `left`, `right`, `no_left`, `no_right`, `bus_stop`,
`parking`. Подтверждение требует три последовательных кадра с единственным
знаком. Порог сходства меняется через `--minimum-score`, число кадров — через
`--confirm-frames`. Перед заездом проверьте распознавание на печатных знаках
полигона и убедитесь, что реальные условия освещения дают устойчивый результат.

Этот профиль запускает инфраструктуру и распознавание. Он не строит маршрут по
знакам и не даёт роботу команд движения: существующий автомат «Эвакуации» для
«Города» неприменим. Навигационные цели задаются через RViz после проверки
знаков, а остановку на 2 секунды у зоны посадки контролирует оператор.
