# Оформление веб-пульта IJKbot

Направление согласовано с оператором: графитовая приборная панель с зелёным
акцентом по ориентиру ИИИ РТУ МИРЭА. HEX `#78c83c` — выбранный интерфейсный
оттенок, а не заявленное точное значение из брендбука.

Продукт — рабочий пульт мобильного робота. Характер — точный, спокойный,
инженерный. Визуальная среда — лабораторные приборы, нейтральные матовые панели.
Основные визуальные элементы — реальные карта и радар. Фирменная деталь —
направленный маркер робота, повторяющийся на джойстике, карте и радаре.

## Девять проходов

1. Отступы: шаг 4 px, единые поля панелей и высоты управляющих элементов.
2. Цвет: графитовая шкала, три роли текста, зелёный акцент; красный оставлен
   аварийной остановке. Убраны свечение и цветные градиенты джойстика.
3. Иконки: локальный спрайт Lucide, размер 18 px и штрих 1,5 px.
4. Текст: обычный регистр, контекстные названия страниц, краткие подписи.
5. Типографика: локальные IBM Plex Sans и IBM Plex Mono для чисел и метаданных.
6. Компоновка: боковая навигация 240 px, шапка 64 px, адаптация до одной колонки.
   На телефоне меню раскрывается отдельно, E-STOP остаётся видимым.
7. Детали: видимый keyboard focus, спокойные hover/disabled состояния,
   выбранная карта отмечается явно, основные DDS-показатели выделены размером.
8. Визуальные элементы: радар и карта используют общую палитру; направленный
   маркер учитывает прежние координаты и TF. При изменении размера карта
   вписывается в доступную область. Изображения не генерировались.
9. Движение интерфейса: только краткие переходы цвета и открытия меню;
   учтён prefers-reduced-motion, фоновых анимаций нет.

Функции семи разделов, ID управляющих элементов, пределы скоростей и защитные
механизмы сохранены. Внешние запросы для отображения страницы не требуются.
