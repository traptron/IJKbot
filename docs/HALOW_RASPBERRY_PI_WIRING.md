# HT-HC01P → Raspberry Pi 4B: подключение через SPI0

Подготовлено 2026-11-02 для переходника с подписями
3V3, GND, INT, RESET, BUSY, WAKE, CLK, MISO, MOSI, CS.
Это выбранная схема для собственного Device Tree overlay, а не распиновка
готового HAT Heltec. Подписи на переходнике определяют назначение проводов.

- Raspberry Pi 4 Model B Rev 1.2, Ubuntu 24.04.5 LTS.

## Таблица проводов

Номера во втором столбце — **физические контакты 40-контактного разъёма**.
BCM-номера нужны для настройки драйвера, а не для отсчёта контактов.

| Переходник HaLow | Физический контакт Pi | Назначение / BCM |
| --- | ---: | --- |
| 3V3 | 17 | Питание 3,3 В |
| GND | 6 | Земля |
| INT | 11 | GPIO17 |
| RESET | 13 | GPIO27 |
| BUSY | 18 | GPIO24 |
| WAKE | 7 | GPIO4 |
| CLK | 23 | GPIO11 / SPI0 SCLK |
| MISO | 21 | GPIO9 / SPI0 MISO |
| MOSI | 19 | GPIO10 / SPI0 MOSI |
| CS | 24 | GPIO8 / SPI0 CE0 |

Соответствие SPI0 и физических контактов:
<https://www.raspberrypi.com/documentation/computers/raspberry-pi.html#spi>.
INT/RESET/BUSY/WAKE назначены на выбранные свободные GPIO; будущий overlay
должен использовать именно эти назначения. Физические номера совпадают
с ранее выбранной разводкой Orange Pi, но BCM/GPIO и SPI-контроллер другие.

## Порядок подключения

1. Завершить работу Pi командой `sudo poweroff`, дождаться остановки
   и отключить питание, включая возможное питание через подключённые устройства.
2. Убедиться, что выбранные контакты физически свободны.
3. Определить контакт 1 по маркировке платы. Нечётные контакты образуют
   один ряд (1, 3, 5, …), чётные — другой (2, 4, 6, …).
4. Соединить провода по таблице, оставляя их короткими; подключить антенну.
5. Проверить питание: к 3V3 идёт контакт 17, **не 5 В с контактов 2/4**.
6. Включить Pi и подтвердить сборку перед аппаратным probe.

Питание от 3,3 В Pi — стартовая схема для стенда; запас тока и стабильность
под радионагрузкой не проверены. При просадках потребуется отдельный
стабилизированный источник 3,3 В с общей землёй, без параллельного
соединения выходов двух источников питания.

Одного `dtparam=spi=on` недостаточно для работы HaLow: потребуется драйвер,
отдельный overlay с заменой spidev на SPI0 CE0, firmware и проверенный BCF.
