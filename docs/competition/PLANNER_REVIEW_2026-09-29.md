| --- | --- |
| `/scan_raw`, `/scan` | Оба поступали; медианный возраст сообщения около 0,08 с. |
| `/odom`, динамический `/tf` | За 10 с не пришло ни одного сообщения. |
| Драйвер приводов | Зафиксировал ошибку сервопривода 2 (`error bits 32`) и остановил публикацию одометрии. Оператор сообщил, что сейчас приводы отключены от Pi. |
| Nav2 costmaps | Постоянно отбрасывали сканы с ошибкой `timestamp ... earlier than all the data in the transform cache`, поскольку динамический переход `odom -> base_footprint` перестал обновляться. |
| `ComputePathToPose`, заданный старт | Путь `(2.5, 2.15) -> (2.7, 2.15)` построен: 7 поз, результат успешен. Значит сам `planner_server` и плагин Navfn работоспособны. |
| Неудачная цель | `(2.0, 2.0) -> (2.2, 2.0)` не построена; конечная клетка имела стоимость 99 в global costmap (зона инфляции). Снижать безопасную инфляцию ради этой цели нельзя. |
| Неизвестная область | Статическая карта содержала 3276 неизвестных клеток, но часть внешней области global costmap показывала как свободную из-за параметра `track_unknown_space` по умолчанию. |

Отдельный риск нагрузки: на Pi автоматический отрицательный тест QR-декодера на шумном кадре занял 144 с на одном ядре. Совместную нагрузку QR и Nav2 ещё нужно измерить; это наблюдение не объясняет отсутствие `/odom`, поскольку приводной драйвер уже защёлкнул ошибку.

Ошибка `32` по [документации Feetech](https://www.feetechrc.com/Data/feetechrc/upload/file/20201127/start%20%20tutorial201015.pdf) обозначает защиту от перегрузки. Она относится к ранее записанному ответу сервопривода; при отключённых сейчас приводах повторно проверить аппаратное состояние невозможно. Автоматически сбрасывать защёлкнутую ошибку и возобновлять движение нельзя.
